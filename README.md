
# 🎮 EntreFormas

Bem-vindo ao **EntreFormas**!

## 📥 Como instalar

Siga os passos abaixo para baixar e executar o jogo no Windows.

### 1. Acesse a última versão
Na página do repositório do GitHub, localize a seção **Releases**, no lado direito da página, e clique na versão mais recente disponível.

### 2. Baixe o jogo
Na seção de arquivos da release, baixe o arquivo:

`DefaultWindowsEXE.zip`

### 3. Extraia os arquivos
Após o download, localize o arquivo `.zip`, clique com o botão direito sobre ele e selecione **Extrair Tudo...**.

Escolha uma pasta de destino e aguarde a extração terminar.

### 4. Execute o jogo
Abra a pasta extraída e localize o executável **EntreFormas**.

Dê dois cliques no arquivo para iniciar o jogo.

## ✅ Pronto!

Agora é só aproveitar o **EntreFormas**!

---

**Requisitos:** Windows  
**Distribuição:** Arquivo ZIP disponível na seção Releases do GitHub.
