# 🎮 EntreFormas

**EntreFormas** é um jogo educativo desenvolvido com o objetivo de ensinar conceitos de geometria de forma interativa.

Durante o jogo, o jogador deve coletar recursos, interagir com máquinas e utilizar formas geométricas para realizar atividades dentro da fábrica. A proposta é apresentar conceitos de geometria por meio das próprias mecânicas do jogo.

---

## 💻 Requisitos

### Para executar a versão compilada

- **Sistema operacional:** Windows
- Não é necessário instalar a Godot ou outros programas.

### Para abrir e executar o projeto

- **Sistema operacional:** Windows
- **Godot Engine:** 4.7.2
- **Git:** necessário apenas caso o projeto seja clonado pelo terminal.

---

## 📥 Como baixar o jogo

Para apenas jogar o EntreFormas, é recomendado utilizar a versão compilada disponível nas **Releases** do repositório.

### 1. Acesse a última versão

Na página do repositório do GitHub, localize a seção **Releases** e acesse a versão mais recente disponível.

### 2. Baixe o jogo

Na seção de arquivos da Release, baixe:

`DefaultWindowsEXE.zip`

### 3. Extraia os arquivos

Após o download, localize o arquivo `.zip`, clique com o botão direito e selecione **Extrair Tudo...**.

Escolha uma pasta de destino e aguarde a extração terminar.

### 4. Execute o jogo

Abra a pasta extraída e localize o executável do **EntreFormas**.

Dê dois cliques no arquivo para iniciar o jogo.

---

## 📂 Como baixar ou clonar o projeto

Também é possível baixar o código-fonte diretamente pelo GitHub.

### Baixar como ZIP

1. Na página principal do repositório, clique em **Code**.
2. Selecione **Download ZIP**.
3. Extraia o arquivo em uma pasta de sua preferência.

### Clonar com Git

Clique em **Code**, copie o endereço HTTPS do repositório e execute:

```bash
git clone URL_DO_REPOSITORIO
```

Depois, acesse a pasta criada pelo Git.

---

## ⚙️ Configuração do ambiente

Para executar o projeto pelo código-fonte:

1. Instale a **Godot Engine 4.7.2**.
2. Abra a Godot.
3. Selecione **Importar**.
4. Localize a pasta do projeto.
5. Selecione o arquivo:

```text
project.godot
```

6. Importe o projeto.

Não é necessário realizar nenhuma configuração adicional para executar a versão compilada disponível nas Releases.

---

## ▶️ Como executar o projeto pela Godot

Com o projeto aberto na Godot:

1. Aguarde a importação dos recursos do projeto.
2. Clique no botão **Executar Projeto** no canto superior direito da engine.

Também é possível utilizar o atalho:

```text
F6 / F5
```

Para executar o jogo completo, utilize a opção **Executar Projeto (F6/F5 conforme configuração da engine)**.

---

## 🕹️ Como iniciar uma partida

Ao executar o EntreFormas, a partida é iniciada automaticamente.

Não existe atualmente um menu principal antes do início do jogo.

Durante a partida existe um **menu de contexto** que apresenta ao jogador o ciclo básico de funcionamento do jogo e auxilia na compreensão das principais mecânicas.

---

## 🎮 Controles

| Controle | Função |
|---|---|
| **W** | Movimentar o personagem para cima |
| **A** | Movimentar o personagem para a esquerda |
| **S** | Movimentar o personagem para baixo |
| **D** | Movimentar o personagem para a direita |
| **Mouse** | Movimentar o cursor e selecionar elementos |
| **Botão esquerdo do mouse (Mouse1)** | Interagir com elementos e arrastar peças |

---

## 🎯 Objetivo do jogador

O objetivo do jogador é interagir com a fábrica, coletar recursos e utilizar as mecânicas disponíveis para avançar pelas atividades apresentadas.

Uma das principais propostas do jogo é utilizar formas geométricas como parte das mecânicas, fazendo com que o jogador aprenda conceitos de geometria enquanto interage com as máquinas.

---

## 📐 Mecânicas básicas

Atualmente, o jogador pode:

- Movimentar-se pelo cenário;
- Coletar recursos;
- Interagir com elementos do ambiente;
- Vender itens;
- Interagir com máquinas;
- Manipular peças geométricas;
- Utilizar o sistema de montagem de formas geométricas;
- Consultar o menu de contexto para entender o ciclo básico do jogo.

---

## 📈 Progressão, vitória e derrota

A versão atual do EntreFormas **não possui uma condição definitiva de vitória ou derrota**.

O jogador pode explorar e utilizar as mecânicas disponíveis na versão atual.

Ao finalizar a experiência disponível, existe a opção de **rejogar**, permitindo iniciar novamente a partida.

---

## ⚠️ Limitações conhecidas

A versão atual ainda está em desenvolvimento e possui algumas limitações:

- A velocidade de movimentação do personagem está acima do valor desejado;
- A mecânica responsável por fazer as máquinas quebrarem está atualmente desativada;
- Nem todas as máquinas planejadas estão disponíveis;
- Atualmente estão disponíveis apenas as máquinas de **triângulo** e **quadrado**;
- O jogo ainda não possui uma condição definitiva de vitória ou derrota.

---

## 🚧 Funcionalidades ainda não implementadas

Entre as funcionalidades planejadas que ainda não estão disponíveis ou finalizadas estão:

- Reativação da mecânica de quebra das máquinas;
- Implementação das demais máquinas;
- Expansão das formas geométricas utilizadas nas mecânicas;
- Ajustes de balanceamento, incluindo a velocidade de movimentação do personagem;
- Expansão da progressão e do conteúdo disponível durante a partida.
